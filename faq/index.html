FAQ

GAMEPLAY

What type of server is ChromaBit?
ChromaBit is a spawner-based Economy SMP. Mob spawners are a core part of the economy they generate sellable drops that you use to build wealth, run shops, and climb the balance leaderboard.
How does the rank system work?
Progress through ranks as you play using /rankup
Each rank unlocks new perks. Acheieving the highest rank grants exclusive items such as Sell Chests.
How do spawners work?
Spawners store mob drops directly inside them right-click a spawner to open its storage and collect your loot. Place a hopper underneath to automate collection. Spawners can be picked up from the world, purchased via /shop, or won from the Spawner Crate at spawn (keys available through ranking up, voting, or the store).

PRIZES

How do server events work?
Events are announced in our Discord along with the rules and the closing date. The winner takes home 100 store credit, and the top 5 all earn credit: 100, 50, 25, 10, and 5. No entry fee required, just play.
How do I receive my prize?
Prizes are paid out as store credit. Winners will need to submit a ticket in the #prize-claims channel, and the credit is applied to your account so you can spend it on ranks, crate keys, or anything else in the store.

GENERAL

What is ChromaBit?
ChromaBit is a competitive Economy SMP Minecraft server. Players build wealth through a player-driven economy, compete on the balance leaderboard, and win store credit in server events.
What is an Economy SMP Minecraft server?
An Economy SMP is a Survival Multiplayer server built around a player-driven economic system. Players earn in-game currency by farming, trading, and running shops, then compete for top spots on leaderboards. On ChromaBit, server events pay out store credit to the top finishers.
What is the server IP address?
The server IP is play.chromabit.us.
Is ChromaBit Java or Bedrock Edition?
ChromaBit runs on Java Edition. Join our Discord for the latest info on supported versions and any cross-play options.
Does ChromaBit have grief protection?
Yes. Your builds, land, and storage are fully protected by grief prevention. You can focus on competing in the economy without worrying about other players destroying your work.
